# Himanshu — Personal Portfolio

An interactive, samurai-themed 3D portfolio showcasing work in Data Science, AI/ML Engineering, and Intelligent Systems.

## Live Site
[portfolio0311.netlify.app](https://portfolio0311.netlify.app/)

## Highlights
- **Interactive 3D Katana & Visual Storytelling**: Built with Three.js/WebGL showcasing a hand-crafted Japanese aesthetic, interactive string impulses, and scroll-driven scenes.
- **Scroll-Driven Journey**: Smooth thematic progression from hero introduction through interactive skill matrices, experience tree, featured engineering projects, and a scroll-revealed interactive contact desk.
- **Projects Showcase**: Highlighting end-to-end applications including autonomous multi-agent systems, spatio-temporal traffic prediction, hybrid recommendation engines, and 3D virtual spaces.
- **AJAX Contact Form**: Fully integrated Netlify Form submission with bot honeypot validation and in-scene feedback.

## Tech Stack
- **Framework & Runtime**: Nuxt.js / Vue 3 (Static Site Generation)
- **3D Graphics & Animation**: Three.js, Canvas, CSS Custom Property scroll mechanics
- **Hosting & Deployment**: Netlify (with custom headers, caching, and form processing)

## Deployment
Deployed as a static site directly to Netlify. Form submissions are processed by Netlify Forms.
